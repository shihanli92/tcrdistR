# Look up a single BLOSUM62 score for two amino acids

Look up a single BLOSUM62 score for two amino acids

## Usage

``` r
rcpp_blosum62_lookup(aa1, aa2)
```

## Arguments

- aa1:

  Single-letter amino acid code (length-1 character string).

- aa2:

  Single-letter amino acid code (length-1 character string).

## Value

Integer BLOSUM62 score for the pair.
