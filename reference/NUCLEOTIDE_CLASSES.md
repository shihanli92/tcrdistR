# IUPAC degenerate nucleotide classes (lowercase)

Named list mapping each IUPAC nucleotide symbol (lowercase) to a
character string of its constituent standard bases (a, c, g, t). Matches
the Python `nucleotide_classes_lower_case` dictionary used by CoNGA.

## Usage

``` r
NUCLEOTIDE_CLASSES
```

## Format

A named list of length 15.
