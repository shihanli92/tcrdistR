# Create a zero V-region distance matrix with matching gene names

Create a zero V-region distance matrix with matching gene names

## Usage

``` r
.zero_v_dist_matrix(v_dist)
```

## Arguments

- v_dist:

  A named square `NumericMatrix` from
  `.compute_v_region_distance_matrix()`.

## Value

A zero matrix with the same dimensions and row/column names.
