# Standard 20 amino acid single-letter codes

A character vector of the 20 standard amino acids in alphabetical order,
ported from Python CoNGA `amino_acids.py`.

## Usage

``` r
AMINO_ACIDS
```

## Format

A character vector of length 20.

## See also

[`bsd4_matrix`](https://shihanli92.github.io/tcrdistR/reference/bsd4_matrix.md),
[`weighted_cdr3_distance`](https://shihanli92.github.io/tcrdistR/reference/weighted_cdr3_distance.md)

## Examples

``` r
AMINO_ACIDS
#>  [1] "A" "C" "D" "E" "F" "G" "H" "I" "K" "L" "M" "N" "P" "Q" "R" "S" "T" "V" "W"
#> [20] "Y"
length(AMINO_ACIDS)  # 20
#> [1] 20
```
